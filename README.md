## About

BookForge is a book management and discovery platform. Search for books, build reading lists, track your progress, and get personalized recommendations.

## Features

- 🔍 **Book Search** — Find any book with powerful search
- 📖 **Reading Lists** — Create and manage personal libraries
- ⭐ **Reviews & Ratings** — Rate and review books
- 🎯 **Recommendations** — Get personalized book suggestions
- 📱 **Responsive** — Beautiful UI on any device

## Tech Stack

| Layer | Technology |
|-------|-----------|
| Framework | Next.js |
| Language | TypeScript |
| Styling | Tailwind CSS |
| API | Book APIs integration |

## Getting Started

```bash
git clone https://github.com/foxnaim/BookForge.git
cd BookForge
yarn install
yarn dev
```
